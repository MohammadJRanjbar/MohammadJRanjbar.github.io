# mohammadjranjbar.github.io

Personal site — hand-written static HTML/CSS/JS, no build step. Served directly by GitHub Pages (`.nojekyll`).

- `index.html`, `publications/`, `projects/` — main site
- `ParsVoice/`, `PARSA-Bench/`, `PersianMedQA/`, `PersianPunc/` — paper pages, each themed with its own paper's color palette
- `assets/` — shared CSS, JS, favicon, audio clips
- `assets/track.js` — visitor analytics (GoatCounter, no cookies): CV, paper, dataset and profile clicks, BibTeX, audio plays, easter eggs. Dashboard: https://mohammadjranjbar.goatcounter.com. Open any page with `#toggle-goatcounter` to stop counting your own visits.
